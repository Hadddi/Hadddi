# مدیریت کلاس من — پروژه APK آفلاین

این پروژه، فایل HTML برنامه را داخل یک پوسته اندرویدی (Capacitor) بسته‌بندی می‌کند. محتوای برنامه داخل APK قرار می‌گیرد و برای باز کردن صفحات اصلی برنامه به اینترنت یا وب‌سایت نیاز ندارد. داده‌ها با `localStorage` روی همان دستگاه ذخیره می‌شوند.

## ساخت APK بدون Android Studio (با GitHub Actions)

این روش از Android Studio استفاده نمی‌کند، اما برای ساخت فایل APK به یک حساب GitHub و اتصال اینترنت هنگام ساخت نیاز دارد.

1. فایل ZIP را از حالت فشرده خارج کنید.
2. در GitHub یک مخزن جدید بسازید.
3. محتوای این پوشه را در مخزن بارگذاری کنید (از جمله پوشه مخفی `.github`).
4. وارد تب **Actions** شوید و گردش‌کار **Build offline Android APK** را اجرا کنید؛ اگر اجرای خودکار فعال است، با push کردن فایل‌ها هم ساخته می‌شود.
5. پس از پایان موفق، در اجرای workflow بخش **Artifacts** فایل `class-manager-offline-debug-apk` را دانلود کنید.
6. ZIP دانلودشده را باز کنید و `app-debug.apk` را به گوشی منتقل و نصب کنید. ممکن است Android برای نصب از منبع موردنظر اجازه بخواهد.

## نکات مهم

- این خروجی، APK آزمایشی (debug) است و برای نصب شخصی مناسب است؛ برای انتشار رسمی در فروشگاه‌ها، باید نسخه release امضا شود.
- برنامه برای استفاده روزمره به اینترنت نیاز ندارد، اما خود فرایند ساخت در GitHub آنلاین است.
- داده‌ها روی همان گوشی و در فضای ذخیره‌سازی برنامه نگهداری می‌شوند. پاک‌کردن داده‌های برنامه یا حذف برنامه ممکن است داده‌ها را از بین ببرد؛ از پشتیبان JSON موجود در برنامه استفاده کنید.
- قلم‌ها از فونت‌های محلی دستگاه/فونت‌های جایگزین استفاده می‌کنند تا برای نمایش متن به Google Fonts وابسته نباشد.
- اصلاح شناسه: تابع `genId()` اکنون به‌جای فراخوانی بازگشتی خودش، از `crypto.randomUUID()` استفاده می‌کند.
- قبل از واردکردن اطلاعات واقعی دانشجویان، نصب، ثبت درس/دانشجو، حضور و غیاب، نمرات، ورود CSV و تهیه/بازیابی نسخه پشتیبان را آزمایش کنید.
